# pyu
### A sleek, minature package manager.

## NOTE: This is the SERVER software. 
To see the client, go to [here](https://github.com/moakdoge/pyu-client)

## Overview
pyu is a cli-driven, language independant package manager built to be as fast and light as possible, relying on as few libraries as possible.

## Key Features
* Easy to use and set up, taking only ~5 minutes to set up
* A small footprint, taking under 15MiB of RAM.
* Supports any programming language.
* Designed for snippets from the start.
* Handles dependancies, full PEP 440 versioning support
* Easy to set up snippeting system.

# Running
```bash
> git clone https://github.com/moakdoge/pyu
cd pyu
python3 -m pip install -r requirements.txt
python3 server.py
```
